Представете си, че имате Hopfield мрежа с 4 неврона (A, B, C, D), които са свързани помежду си. Нека тези неврони имат следните тегла на връзките:

Тегло между A и B: 1
Тегло между A и C: -1
Тегло между A и D: 1
Тегло между B и C: 1
Тегло между B и D: -1
Тегло между C и D: 1
Сега, искаме мрежата да научи да разпознава кръг и квадрат. Нека представим, че кръгът се представя чрез активиране на невроните A и D, а квадратът чрез активиране на невроните B и C.

Обучение на мрежата:

Подаваме сигнали, който представляват кръг (например, активираме A и D).
Актуализираме теглата в съответствие с входните сигнали и правим това многократно, докато мрежата "научи" как да разпознава кръг.
Таблица с тегла преди обучение:



A  B  C  D
0  0  0  0
Таблица с тегла след обучение:



A  B  C  D
0  0  0  0
1  0  0  1
Правим същото и за квадрата (например, активираме B и C).

Таблица с тегла след обучение за и двата образа:



A  B  C  D
0  0  0  0
1  0  0  1
0  1  1  0
Разпознаване на образ:

Подаваме нов образ, който може да бъде деформиран кръг или квадрат (например, активираме A и D, но с лека деформация).
Мрежата трябва да се справи с деформациите и да разпознае, че входът е близък до един от обучените образи.
Пример:



Вход:  1  0  0  1
Изход: 1  0  0  1 (кръг)
